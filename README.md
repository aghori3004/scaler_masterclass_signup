# Scaler AI Skill-Bridge

An AI-powered tool designed to generate personalized diagnostic assessments for Scaler Masterclasses. Using **Google Gemini**, it analyzes curriculum content to create pre-requisite knowledge quizzes, provides tailored feedback, and routes users to relevant alumni success stories.

[**View Live Deployment**](https://scalermasterclassapp-4bbaysgbbyzbqsj7ehvtdp.streamlit.app/)

## Features

-   **Curriculum Analysis**: Automated scraping and parsing of Masterclass content.
-   **Diagnostic Quizzes**: 5-question AI-generated tests to assess readiness.
-   **Personalized Insights**: Instant feedback and "Lead Warmth" scoring for CRM integration.
-   **Smart Routing**: Matches candidates with alumni profiles based on background and experience.

## Quick Start

1.  **Clone & Install**
    ```bash
    git clone https://github.com/YOUR_USERNAME/scaler-ai-bridge.git
    pip install -r requirements.txt
    ```

2.  **Run Application**
    ```bash
    streamlit run app.py
    ```

**Configuration**: A Google Gemini API key is required via the application sidebar.
